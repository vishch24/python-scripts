# Python Scripts

A comprehensive hands-on collection of Python automation scripts designed for covering system administration, cloud resource management, container handling, and CI/CD pipeline utility tasks.

## Repository Structure & Modules

- `01-system-health`: Check CPU, memory, disk usage, and send alerts.
- `02-file-and-logs`: Parse log files, rotate logs, and clean up old directories.
- `03-docker-management`: Programmatically start, stop, and inspect containers via Docker SDK.
- `04-aws-boto3`: Automate EC2 instance states and list S3 bucket metrics.
- `05-kubernetes-api`: Query and restart pods across namespaces using the Kubernetes client.
- `06-api-alerts`: Send webhook notifications to Slack or Discord on service failures.
